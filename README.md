## ⚙️ Development Command Protocols

To initialize and launch this neural project locally:

1. **Clone the Core Payload**
   ```bash
   git clone https://github.com/24f1001022/Tds.git
   cd roe/portfolio
   ```

2. **Initialize Dependencies**
   ```bash
   npm install
   ```

3. **Launch Dev Uplink Server**
   ```bash
   npm run dev
   ```
   *The client environment will deploy locally at `http://localhost:5173/`.*

4. **Compile Production Bundle**
   ```bash
   npm run build
   ```
   *Compiles fully optimized static assets directly into `./dist/`.*
